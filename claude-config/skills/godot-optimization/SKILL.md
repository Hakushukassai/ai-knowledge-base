# Godot 4: 大量インスタンスの最適化

見た目が同じオブジェクト(敵・弾丸・アイテムなど)を同時に大量に配置する設計を考えるときは、**最初から個別Nodeで作らない**。

## 判断基準

「同じ見た目のオブジェクトが同時に50体以上存在しうるか」で判断する。存在しうるなら、最初から `MultiMeshInstance3D` で設計する。

## なぜ個別Nodeを避けるべきか

個別のNode(`CharacterBody3D` など)は、それぞれが `_process` / `_physics_process` を持つため、200体を超えたあたりからそのオーバーヘッドで明確にフレームが落ちる。`MultiMeshInstance3D` は同一メッシュの大量インスタンスを1回の描画呼び出しでまとめて処理できるため、この問題が起きない。

## 実装のタイミングが重要

後から個別Node実装を `MultiMeshInstance3D` に移行するコストは高い(当たり判定や個別ロジックの持ち方が根本的に変わるため)。判断基準に該当するなら、**設計の最初の段階で** `MultiMeshInstance3D` を選ぶこと。

## 参考にした実際の事例

- RESODIVE: 敵の大量発生でフレームレートが低下した事例
- DEPTH//: 弾丸の大量発生でフレームレートが低下した事例
