# Apple HIG Source Map

Use this as a coverage map, not as a frozen copy of Apple's documentation. Start from the [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) and open only the sections relevant to the current artifact. Record the page title, URL, and access date in the design handoff.

## Platform Foundations

Select the platform guidance from the HIG navigation:

- Designing for iOS
- Designing for iPadOS
- Designing for macOS
- Designing for watchOS
- Designing for tvOS
- Designing for visionOS

Confirm supported OS versions and device classes from current Apple developer documentation when a platform feature or component may have changed.

## Foundations Coverage

Review the applicable foundation pages: accessibility, app icons, color, dark appearance, inclusion, layout, materials, motion, privacy, right-to-left layouts, SF Symbols, typography, and writing. Frequently used direct pages include:

## Patterns Coverage

From the current HIG index, inspect patterns that govern the flow: account management, collaboration and sharing, data entry, drag and drop, feedback, file handling, full screen, launching, live content, loading, modality, multitasking, navigation and search, notifications, onboarding, permissions, settings, undo/redo, and media or immersive experiences. Use the current index title and URL because Apple can reorganize or rename subsections.

## Components Coverage

Inspect the component families actually used: content presentation, layout and organization, menus and actions, navigation and search, presentation, selection and input, status, and system experiences. Check platform availability and behavior before specifying a cross-platform component.

## Inputs Coverage

Cover all supported inputs, including touch, pointer, keyboard, game controller, Apple Pencil, remote, Digital Crown, accessibility switches, and visionOS eye/hand or indirect input as applicable. Never design only for the input used during development.

## Technologies and System Experiences

When the product uses an Apple technology, open its current HIG page and developer documentation. Examples include Apple Pay, HealthKit, HomeKit, iCloud, in-app purchase, Live Activities, maps, machine learning, Sign in with Apple, SharePlay, Siri, widgets, augmented reality, and spatial/immersive experiences.
